# ۲۱ — استراتژی تست، معیار پذیرش و دادهٔ آزمایشی

## لایه‌های تست
- **Unit:** parse مقدار null رشته‌ای، timestamp و parse JSON؛ نرمال‌سازی تومان/ریال/واحد؛ محاسبهٔ سن؛ محاسبهٔ deviation robust؛ ممنوعیت به‌روزرسانی ناموجودی از عدم پاسخ؛ نگهداری scope.
- **Contract:** schema رویداد، source provenance، version، authorization، idempotency، خطای offer_version و expiry.
- **Integration:** صف نوتیف، چند دستگاه، پاسخ offline، دوبار delivery، پاسخ متناقض، لغو reminder، شیفت و ساعت استثنایی.
- **E2E:** قصد سفر → استعلام → پاسخ دقیق → سفر → گزارش مثبت/منفی → پرونده → اصلاح و امتیاز.
- **Data QA:** integrity، no negative/future timestamp بدون flag، drift، تناسب تعداد با محدودیت cap300، duplicate variant و outlier.
- **Model QA:** temporal split، عدم leakage، calibration، coverage unknown، cold start و اعتبار در رژیم‌های متفاوت.
- **Chaos/Security:** قطع push، اختلال اینترنت منطقه‌ای، DB failover، انقضای auth، حملهٔ spam و جعل گزارش.
