# فایل‌های خام منبع

این پوشه صرفاً کپی فایل‌های اصلی تحویل‌شده در گفت‌وگو است. **README.txt** به محدودیت ۳۰۰ محصول متمایز برای هر فروشگاه، JSON رشته‌ای و مقدار `null` لفظی اشاره می‌کند. اطلاعاتی که در این خروجی نیستند (مثل سابقهٔ موجودی، تأیید لحظه‌ای یا نرخ ارز) را نباید به عنوان دادهٔ موجود مستند کرد.

- `shops.csv`: فروشگاه و نشانی/ساعت اعلامی؛
- `products.csv`: اطلاعات عمومی محصول، مدل و مشخصات؛
- `offers.csv`: پیشنهاد، قیمت، زمان آخرین تغییر قیمت ثبت‌شده؛
- `price_audit_candidates.csv`: خروجی غربالگری پیشین برای بررسی انسانی؛ نه برچسب قطعی خطای قیمت.

SHA256 فایل‌ها و روش آدیت در `../02_DATA/verified_audit.json` آمده است. شرایط استفاده/انتشار مجدد از اطلاعات فروشندگان و نشان‌های برند باید پیش از نشر عمومی ارزیابی شود.
