## ۲. مشخصات و استک فنی

- **فریم‌ورک پایه**: [Next.js 14](https://nextjs.org/) (App Router)
- **کتابخانه‌های کلیدی**:
  - `react` و `react-dom` نسخه ۱۸.۳
  - `leaflet` نسخه ۱.۹.۴ جهت نقشه تعاملی و خوشه‌بندی پین‌ها
  - `lucide-react` برای آیکون‌های مدرن
  - `typescript` برای ایمنی نوع داده‌ها
- **سبک رندرینگ**: Server-Side Rendering (SSR) با بخش‌های تعاملی کلاینت (`'use client'`)
- **درگاه ارتباطی**: پراکسی پویا در `src/app/api/v1/[...path]/route.ts` جهت اتصال بی‌دردسر به بک‌اند محلی یا ابری و برطرف کردن محدودیت‌های CORS.

## ۳. امکانات و قابلیت‌های اصلی

### الف) دستیار هوشمند ترب‌چت (TorobChat AI Assistant)
- گفتگوی طبیعی به زبان فارسی با استفاده از مدل زبانی هوشمند متصل به کاتالوگ ۲۲۵ هزار کالا و ۶۴۰۰ فروشگاه فیزیکی ترب.
- تشخیص هوشمند قصد خرید، تحلیل بودجه، فیلتر برند و ارائه توصیه‌های فنی (مانند هدفون مناسب ورزش، مقایسه شارژرهای اصل و فست‌شارژ، پاوربانک‌های مجاز).
- اضافه کردن مستقیم پیشنهادات گفتگو به نقشه و سبد مراجعه حضوری.

### ب) نمای دسکتاپ دوپنله و نقشه تعاملی خرید حضوری (`web-3.png`)
- نقشه تعاملی با کتابخانه Leaflet و پین‌های خوشه‌بندی‌شده بر اساس قیمت و موجودی.
- نوار جستجوی پیشرفته به همراه چیپ‌های پرتکرار بازار (کیبورد مکانیکی، شارژر ۲۵ وات و...).
- فیلترهای چندمعیاره: «ارزان‌ترین»، «نزدیک‌ترین» و «پیشنهادی الگوریتم».
- نمایش زمان تخمینی رسیدن (ETA)، وضعیت فعالیت فروشگاه و تنوع رنگی موجود در انبار مغازه.

### ج) راهنمای هوشمند رفت‌وآمد و شناسنامه فروشگاه (`web-4.png`)
- ارائه شواهد کامل فروشگاه فیزیکی: آدرس دقیق، ساعت کاری، خط تلفن ثابت و همراه، و سابقه در ترب.
- محاسبه الگوی سفر و پیشنهاد وسیله نقلیه بهینه (مثلاً پیشنهاد ماشین برای مسافت‌های طولانی‌تر جهت کاهش زمان رسیدن و افزایش احتمال بقای موجودی).
- شیوه‌های تسویه: ترب‌پی (TorobPay)، خرید اقساطی، و پرداخت حضوری در مغازه.

### د) موتور مقایسه محصولات در بازار فیزیکی (`web-5.png`)
- امکان مقایسه همزمان تا ۵ کالا.
- مقایسه متغیرهای سنتی (قیمت، باتری، نسخه بلوتوث) در کنار **متغیرهای بازار فیزیکی** (تعداد مغازه‌های موجود در شهر، فاصله نزدیک‌ترین فروشگاه، وضعیت انبار).

### هـ) برگه مشخصات فنی با فیلتر درونی (`web-6.png`)
- پنل جستجوی درونی در پارامترهای فنی کالا (مانند استاندارد ضدآب IPX4، وزن، نوع کدک صوتی و تاخیر حالت گیمینگ).

### و) چرخه استعلام لحظه‌ای از فروشنده (Live Inquiry Experience)
- ارسال مستقیم درخواست استعلام موجودی یا قیمت با دکمه اختصاصی روی کارت فروشگاه.
- نردبان استعلام لحظه‌ای و دریافت نتیجه فروشنده با شمارش معکوس SLA کمتر از ۲ دقیقه.

## ۴. ساختار پوشه‌ها و کدهای پروژه

```
trobapp/
├── public/                 # دارایی‌های ایستا، استایل‌ها، فونت‌ها و اسکریپت‌های هسته
│   ├── js/                 # ماژول‌های جاوااسکریپت (map.js, agent.js, catalog.js, backend.js)
│   ├── css/                # فایل‌های استایل و چیدمان RTL
│   └── img/                # آیکون‌ها و نشان‌های بصری
├── src/
│   └── app/
│       ├── layout.tsx      # چیدمان سراسری برنامه
│       ├── page.tsx        # صفحه اصلی تلفیقی با UI Markup
│       ├── UiScripts.tsx   # بارگذاری هماهنگ کتابخانه‌های نقشه و داده
│       └── api/v1/         # پراکسی هوشمند درخواست‌های API به بک‌اند FastAPI
├── package.json
└── next.config.mjs
```

## ۵. راهنمای اجرا و توسعه محلی

### نصب وابستگی‌ها
```bash
cd trobapp
npm install
```

### اجرای سرور توسعه
```bash
npm run dev
```
اپلیکیشن در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ساخت نسخه نهایی و اجرا
```bash
npm run build
npm start
```
